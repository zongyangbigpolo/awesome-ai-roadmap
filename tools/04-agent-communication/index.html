    Tools · Agent Communication¶

    This module covers A2A discovery, the task state machine, protocol bindings, and collaboration across systems.

    The module follows the v1.0.1 release specification, whose wire-level version is 1.0. Do not mix the older message/stream method or old Agent Card fields into 1.0 examples. A2A defines a collaboration interface; it does not guarantee that multiple agents outperform a single agent.
